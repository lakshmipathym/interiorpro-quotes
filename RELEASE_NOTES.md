# Release Notes - InteriorPro ERP v1.5

**Version:** 1.5.0
**Release Date:** 2026-07-17

## Overview
InteriorPro ERP v1.5 brings the application to enterprise-grade production readiness, with a major focus on the quotation export module. The PDF engine has been fully certified for high-fidelity printing and enterprise distribution.

## Key Highlights
* **Enterprise PDF Quality**: Output documents are now fully optimized for high-resolution A4 printing, with embedded metadata and enhanced visual clarity.
* **Release Engineering**: Build configurations have been locked down. Production builds now utilize R8 minification and resource shrinking for smaller footprint and optimized runtime performance.

## Installation Notes
Please ensure that any previous internal test builds are uninstalled before deploying the new v1.5 production APK. No database schema changes were made during this sprint, ensuring backward compatibility with local data.
