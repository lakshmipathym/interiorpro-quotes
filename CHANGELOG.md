# Changelog

All notable changes to this project will be documented in this file.

## [1.5.0] - 2026-07-17
### Added
- Enterprise-grade PDF generation optimizations.
- High-quality image and vector scaling for logos, seals, and signatures.
- Sharp boundary anti-aliasing and dithering for color blocks.
- Stable metadata embeddings for exported PDF documents.
- Multi-page intelligent break protection to eliminate orphan rows.

### Changed
- Optimizations for A4 output compatibility.
- Build system configured for production releases (R8 minification and resource shrinking).
- Updated internal build identifiers.

### Fixed
- Fixed print-quality regressions for transparent and shaded regions.
